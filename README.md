# rm_soft

Декодеры Reed-Muller и Polar на основе LLR в C++.

## Описание проекта

`rm_soft` — это исследовательский проект на C++, предназначенный для реализации и оценки декодирования кодов Рида–Маллера (Reed-Muller, RM) и Поляра (Polar) на основе log-likelihood ratios (LLR).

Проект ориентирован на:

- реализацию декодеров для RM и Polar кодов;
- работу с мягкими решениями через LLR;
- оценку качества кодирования и декодирования в канале с шумом;
- анализ BER/BLER и сравнение различных параметров схемы.

## Что реализовано

- генерация и декодирование кодов Рида–Маллера;
- построение и обработка кодов Поляра;
- мягкое декодирование на основе LLR;
- поддержка CRC;
- вспомогательные структуры для модуляции и канала;
- утилиты для анализа ошибок и построения графиков.

## Основные компоненты

- `rm_codes.hpp` — реализация кодов Рида–Маллера;
- `polar_mask.hpp` — маски и структуры для кодов Поляра;
- `polar_decoder.hpp` и `polar_scl_codec.hpp` — декодеры;
- `polar_encoder.hpp` — кодирование;
- `modulation.hpp` — вспомогательные функции модуляции;
- `crc.hpp` — поддержка CRC;
- `main.cpp` — точка входа для экспериментов и симуляций;
- `plot_ber.py` и `plot_bler.py` — построение графиков эффективности.

## Сборка

Сборка выполняется обычным компилятором C++:

```bash
g++ -std=c++17 -O2 main.cpp -o rm_soft
```

Если проект будет собираться через CMake или другую систему, можно адаптировать сборку под текущую инфраструктуру.

## Запуск

После компиляции запускается бинарник `rm_soft`:

```bash
./rm_soft
```

Точка входа `main.cpp` предназначена для проведения экспериментов: настройки параметров кода, запуска моделирования, сбора статистики ошибок и оценки качества декодирования.

## Типовой рабочий процесс

1. Задать параметры кода: длину, скорость, тип декодера.
2. Сформировать кодовое слово или маску.
3. Передать символы через шумовой канал.
4. Выполнить LLR-based декодирование.
5. Сравнить выход с исходным сообщением.
6. Посчитать BER/BLER и визуализировать результаты.

## Построение графиков

В репозитории есть Python-скрипты для анализа результатов:

```bash
python3 plot_ber.py
python3 plot_bler.py
```

Они предназначены для визуализации зависимости вероятности ошибки от параметров канала и конфигурации декодирования.

## Примечание

Это не универсальная библиотека для широкого использования, а скорее исследовательский проект для анализа алгоритмов кодирования и декодирования в системах связи. Основной акцент сделан на реализацию и проверку эффективности кодов и декодеров.
