# rm_soft

Декодеры Reed-Muller и Polar Codes на основе LLR в C++.

https://vk.ru/codesandsignals

## Описание проекта

`rm_soft` — это исследовательский проект на C++, предназначенный для реализации и оценки декодирования кодов Рида–Маллера и полярных кодов на основе мягких решений (LLR).

Проект ориентирован на:

- реализацию декодеров для кодов Рида–Маллера и полярных кодов;
- работу с мягкими решениями через LLR;
- оценку качества кодирования и декодирования в канале с шумом;
- анализ BER/BLER и сравнение различных параметров схемы;
- исследование и документирование методов, связанных с алгеброй LLR и их применением в кодировании.

## Что реализовано

- генерация и декодирование кодов Рида–Маллера;
- построение и обработка полярных кодов;
- мягкое декодирование на основе LLR;
- вспомогательные структуры для модуляции и канала;
- утилиты для анализа ошибок и построения графиков;
- научный/методический материал в виде PDF-документа.

## Сборка

Проект использует **C++20** (`std::span`, `std::jthread`, `std::reduce`, concepts).

Сборка через CMake (рекомендуется):

```bash
cmake -S . -B build
cmake --build build --config Release
```

Или напрямую компилятором:

```bash
g++ -std=c++20 -O2 -pthread main.cpp -o rm_soft
```

## Запуск

После сборки запускается бинарник `rm_soft` (в `build/` при сборке через CMake):

```bash
./rm_soft [rm|ssc|sc]
```

Аргумент задаёт схему кодирования и декодирования:

- `rm` — коды Рида–Маллера (RM(2, 6) + 16-QAM);
- `ssc` — полярный код с Fast-SSC декодером (по умолчанию);
- `sc` — полярный код с классическим SC декодером.

Симуляция работает непрерывно, уточняя статистику, и пишет результаты в
`live_results_<тип>_<r>_<m>.csv` (например, `live_results_polar_fast_ssc_2_6.csv`).
Для остановки нажмите `Ctrl+C`; файл с результатами сохраняется на каждом шаге.

Точка входа `main.cpp` предназначена для проведения экспериментов: настройки параметров кода, запуска моделирования канала, оценки BER/BLER и сравнения различных схем декодирования.

## Типовой рабочий процесс

1. Задать параметры кода: длину, скорость, тип декодера.
2. Сформировать кодовое слово или маску.
3. Передать символы через шумовой канал.
4. Выполнить LLR-based декодирование.
5. Сравнить выход с исходным сообщением.
6. Посчитать BER/BLER и визуализировать результаты.

## Построение графиков

Скрипты используют `matplotlib`, `numpy`, `pandas` и `scipy`:

```bash
python3 -m pip install -r requirements.txt
```

Графикам нужны результаты **двух** прогонов — RM и полярного кода. Запустите симулятор дважды
(в отдельных терминалах или последовательно, останавливая `Ctrl+C`):

```bash
./rm_soft rm   # создаст live_results_rm_2_6.csv
./rm_soft ssc  # создаст live_results_polar_fast_ssc_2_6.csv
```

Затем постройте графики:

```bash
python3 plot_ber.py
python3 plot_bler.py
```

Они сохраняют `ber_comparison.svg` и `bler_comparison.svg` и показывают зависимость вероятности
ошибки от отношения сигнал/шум для разных схем декодирования.

Диаграмма короткого цикла Таннера строится отдельно:

```bash
python3 tanner_cycle.py   # сохранит tanner_graph_cycle.svg
```
